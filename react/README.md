# @doxa/react

`@doxa/react` is the one-way React adapter for `@doxa/core`.

```sh
pnpm add @doxa/react react
```

It provides React hooks for Doxa document selectors, readable values, and
history. It does not add a second document store or mutation model; canonical
state remains owned by `@doxa/core`.

For the full guide, API examples, and contribution instructions, see the Doxa
repository.
