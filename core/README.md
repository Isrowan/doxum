# @doxa/core

`@doxa/core` is the framework-neutral typed runtime for complex mutable documents.

```sh
pnpm add @doxa/core
```

It owns schema, canonical document state, operations, transactions, history,
impact, subscriptions, and framework-neutral projections. For the full guide,
API examples, and contribution instructions, see the Doxa repository.

## React

For the React adapter, install `@doxa/react` alongside React.

```sh
pnpm add @doxa/react react
```
